# CS Demo Manager · Team scouting

Companion application for your Counter-Strike demos.

This fork adds individual round-clock playback, team buy comparisons and imported FACEIT season scouting.

- [Download the Windows viewer and 13 Solace season demos](https://github.com/stooken/cs-demo-manager-scouting/releases/tag/scouting-solace-s59)
- [Set up the viewer, import the demos and install the optional Firefox bridge](scouting/README.md)
- [Browse recordings by map and opponent](scouting/DEMOS.md)
